      Enforced in code, covered by tests
      Write-ahead log
      A row is written before an email leaves; a crash mid-send blocks a resend instead of emailing twice.
      Duplicate lock
      One send per creator and per inbox, checked in code and enforced by unique indexes in SQLite.
      No blind retries
      If n8n doesn't answer, the send is marked unconfirmed, never retried automatically.
      Do-not-contact
      An unsubscribe reply goes on a suppression list that every campaign checks before sending.
      Published emails only
      Taken only from the creator's own description, website or business line. 95 are marked Not Found, none guessed.
      Private data stays private
      Audience age and gender are private YouTube Analytics, so they are marked unavailable.
      Instagram by hand
      Meta allows no automated cold DMs; 160 DMs are queued for a person to send.
      Human review gate
      Messages that fail validation three times are held, never sent automatically.
