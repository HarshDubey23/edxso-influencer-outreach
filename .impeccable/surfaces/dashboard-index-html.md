Scope: public showcase landing (dashboard/index.html) for the outreach engine; visitor mode Persuade. The working
dashboard moves to dashboard/app.html (Operate) and inherits this world in restrained form.

Audience/job: EDXSO reviewers deciding in minutes whether the work clears the bar. Action: open the live dashboard
(working classifier, creators, messages) or the repository. Proof: real run numbers from data.json, the live
in-browser classifier, real generated messages, real rejection reasons. No personal details on the page.

## Direction contract

THESIS: Results day. 2,629 channels sat the exam; the page is the result sheet: ranked, stamped, every withheld result
with its reason. Refuses the dark AI-landing with gradient headline, metric tiles and a dashboard screenshot.

OWN-WORLD: green felt notice board (#1d3a31 felt with fibre texture) carrying cool white typed sheets (#f6f7f4),
brass pins, red rubber-stamp ink (#c62f26) for verdicts, blue ballpoint (#2342a8) for marks and links, near-black type.
Condensed poster caps (Big Shoulders Display) for headings, Public Sans for prose, JetBrains Mono only for tabular
data (roll numbers, counts, scores).

STORY: the visitor sees the verdict (161 of 2,629 cleared), reads how it was decided step by step with real counts,
sees what was withheld and why, tests the classifier themselves, reads two real letters, checks the rigor ledger, then
opens the dashboard or code.
